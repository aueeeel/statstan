# Forte Vision

Две адаптивные страницы для ForteBank Datathon 2026: `/` — главная с фоновым видео; `/check` — рабочее пространство проверки записи.

## Запуск

Требуется Node.js 20+. Установка зависимостей не нужна.

```sh
npm run dev
```

Откройте http://localhost:4173. Сборка для публикации: `npm run build`; результат находится в `dist/`.

## Vercel

Импортируйте репозиторий в Vercel. Файл `vercel.json` задаёт `npm run build`, каталог `dist` и чистые URL. Переменные окружения для интерфейса не требуются.

## Проверка видео

Интерфейс принимает MOV, MP4 и WebM до 250 МБ. Видео до запуска анализа остаётся на устройстве и воспроизводится через временный object URL. Совместимость предпросмотра MOV зависит от кодека и браузера.

Кнопка «Подключить сервис» задаёт URL вашего сервера и ключ. Ключ хранится только в памяти вкладки. URL сохраняется в localStorage. После перезагрузки ключ нужно ввести снова. Никакие облачные AI API не подключены.

Реальный инференс, веса модели и сервер анализа в этот репозиторий не входят. Без подключённого сервиса кнопка проверки открывает настройки; интерфейс никогда не выдаёт демоданные за анализ пользовательского видео. Деморежим имеет явные пометки, условную схему вместо банковских кадров и отдельное имя JSON-отчёта.

## Контракт локального сервера

`POST /api/v1/analyze`, заголовок `X-API-Key`, multipart-поле `file`. Ответ: `{ "job_id": "..." }`.

`GET /api/v1/jobs/{job_id}`, тот же заголовок. Статусы: `processing`, `done`, `failed`. Клиент опрашивает сервер каждые 1,5 секунды и прекращает ожидание через 5 минут. Сервер должен сам устанавливать лимит исполнения задания и отменять оставшиеся задания при необходимости: отмена ожидания в браузере не останавливает серверный инференс.

```json
{
  "job_id": "example",
  "status": "done",
  "verdict": "violation",
  "violations": [{
    "type": "Название наблюдаемого события",
    "timecode_sec": 12.4,
    "description": "Наблюдаемые действия и основание для проверки",
    "evidence_frames": [{ "timestamp_sec": 12.4, "image_base64": "JPEG_BASE64" }],
    "rule": "Название документа и пункт",
    "source_url": "https://adilet.zan.kz/..."
  }]
}
```

Для `no_violation` массив `violations` должен быть пустым. Поля `rule` и `source_url` расширяют обязательную схему кейса; поддерживается также `normative_source: {title, section, url}`. Источники и кадры должен возвращать реальный сервис. Интерфейс не придумывает нормативные пункты. Решение требует проверки человеком.

Настройте на сервере CORS для домена сайта: методы `GET`, `POST`, `OPTIONS`, заголовок `X-API-Key`. Для публичного HTTPS-сайта используйте HTTPS-адрес сервера. Локальная обработка означает собственный сервер с моделями внутри инфраструктуры команды, без передачи кадров внешним AI API. Vercel размещает статический интерфейс, не модели. Банковские датасеты не включены и не публикуются.

## Состав

- Семантический HTML, CSS, JavaScript без сторонних JS-зависимостей.
- Загрузка перетаскиванием, проверка размера/формата, предпросмотр, отмена ожидания.
- Раскрываемые события, переход по таймкоду, просмотр кадров, экспорт JSON.
- Мобильная компоновка, клавиатурная навигация, настройка уменьшения движения, пауза фонового видео.
- Видео карты предоставлено пользователем. Основной шрифт — Satoshi (Fontshare). Официальный Satoshi не включает кириллицу, поэтому русские буквы отображаются Manrope. Оба шрифта размещены локально в assets/fonts; запросов к внешним серверам шрифтов нет.

Название и оформление — концепт для хакатона, не официальный сервис ForteBank.

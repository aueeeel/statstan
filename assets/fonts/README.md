# Fonts

Satoshi Variable: official Fontshare webfont, weights 300–900.
Source: https://www.fontshare.com/fonts/satoshi
License: https://www.fontshare.com/licenses/itf-free-font-license

Satoshi's official file does not include Cyrillic glyphs. Manrope Variable supplies the Cyrillic fallback at weights 200–800.
Source: https://github.com/google/fonts/tree/main/ofl/manrope
License: SIL Open Font License 1.1, included in Manrope-OFL.txt.

Both fonts are served from this site's own assets. No third-party font requests are needed.
